LocalGrid update signer

Make the signed update file a LocalGrid grid accepts as new firmware. Everything on this page happens in your browser: nothing is uploaded, and it works with no connection once the page is open.

1. Your release key

A grid installs an update only if it was signed with the release key that grid trusts. Make one key for your grid, once, and keep the private file safe: anyone who has it can update your devices, and nobody can sign for you without it.

The public key is the long line starting with 04. It is not a secret: it is what you give a device when you set it up, so that it knows whose updates to accept.

2. Sign a firmware image

Devices install an update only if its serial number is higher than the one they run, so a newer build must have a higher number. The time now, in seconds, is filled in for you and is always higher than last time.

3. Check an update file

Before you give a file to a grid, or when someone gives one to you, check it against the public key you trust.

File layout: a 128-byte header (what the image is for, its length, its SHA-256, the serial number and which key signed it), a 64-byte ECDSA P-256 signature over that header, then the image. The command-line tool tools/lgfw.py in the repository makes and checks the same files.
