Install LocalGrid

Put LocalGrid on a board over its USB cable, then give the board its place in your grid. You need a desktop browser with Web Serial (Chrome or Edge). The grid itself never uses the Internet; only this page does.

This browser cannot talk to a USB serial port. Use Chrome or Edge on a computer.

1. Install the firmware

Installing erases the board. A board that already runs LocalGrid can skip to step 3.

2. Your grid

Every device in one grid shares its keys. Make them once and keep the file: it is what lets you add a device later, and anyone who has it can join your grid.

3. Set up this board

An access point takes a number from 0 to 15 and a name. A handheld takes a number from 1 to 32, different for each handheld in the grid; people's names are set later on the admin page.
