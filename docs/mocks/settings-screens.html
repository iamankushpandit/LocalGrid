Handheld Settings, in the theme's colours

Settings is the one screen built on lv_tabview, and nothing restyles its tab strip, so it gets LVGL's default light theme: a white strip, light green tab names on white, and a blue selected tab. Below is how it renders now, then Settings with Gume's raised tabs and button rows in the Terminal theme's colours. The screen size is the Hosyond 240 × 320, drawn 1.5 times larger.

Now

These colours come from lv_theme_default.c: bg_color_white on the tab strip, and bg_color_primary_muted with a primary bottom border on the selected tab. The tab names use t->text (#D2F5DE), which almost disappears on white.

Proposed, Gume's layout

As in Gume, the selected tab is raised and joins the page, and the others are dimmed. Actions are outlined buttons with the value in accent, a main action is filled with the accent colour, and Restart is filled red. Facts that cannot be changed are plain text rows, so nothing looks tappable unless it is. Every colour is an existing lg_theme role, so no new colour is needed.
